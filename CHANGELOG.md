## v0.1.0-2 - 2026-11-07

Board design: v0.1.0, unmodified.

USB device settings changed:
- idVendor: 0x1209
- idProduct: 0xf543
- iManufacturer: "piers.rocks"
- iProduct: "USB PPPS Hub"
- bcdDevice: The board version (e.g. 0x0010 for v0.1.0)
- iSerial: A random 64-bit value

An EEPROM programmer using a Raspberry Pi Pico or Pico 2 replacing the Raspberry Pi programming instructions.
